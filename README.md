# Перерождение Героя: Клинок Богини ⚔️

Аниме 2D слэшер с элементами RPG и гачи на React + Canvas.

## Сюжет

Кай погибает под колёсами грузовика в нашем мире. Богиня Астрея дарует ему вторую жизнь в
Элирии — мире, который пожирает Владыка Демонов Зеррис. Пройди три главы (Лес Забвения →
Пепельный Город → Цитадель Владыки), победи боссов, прокачай героя и собери отряд из трёх
героинь — Арии, Юки и Лиры. В финале они станут твоими жёнами. 💍

## Геймплей

- **WASD** — движение, **ЛКМ / J** — комбо-атаки, **SPACE** — рывок с неуязвимостью
- **Q** — навык класса, **E** — Ярость Героя / взаимодействие, **F** — фляга Эстуса,
  **TAB / ПКМ** — захват цели, **ESC** — пауза, **M** — звук
- **3 класса** у богини: Рыцарь Клинка, Маг Мороза (авто-ледяные снаряды), Охотник Теней
- **Souls-like**: стамина, фляги Эстуса, руны (теряются при смерти — вернись за ними!),
  очаги-костры для сохранения, телеграфы атак боссов, экран «ТЫ УМЕР»
- **Открытый мир** между главами: параллакс-горы, города с факелами, миникарта, источник
  исцеления, святилище, сундуки, бродячие и **элитные** демоны, золотые врата
- 5 глав, 7 видов демонов + **элиты** с аурой, 5 боссов с фазами, яростью и зонами смерти
- RPG: опыт, уровни, выбор усилений (вампиризм, крит, скорость, фляги, стамина)
- Гача-призыв за руны: редкие / эпические / легендарные благословения
- **Процедурный саундтрек** (WebAudio): отдельные темы для титула, мира, боя, боссов,
  богини и финала — без единого аудиофайла
- **Аниме-дизайн**: сгенерированные key-art фоны, косые неоновые панели, спидлайны,
  кандзи-акценты; прогресс и лучший забег сохраняются в localStorage

## Запуск локально

```bash
npm install
npm run dev
```

## Хостинг на GitHub Pages (автоматически)

В проекте уже есть workflow `.github/workflows/deploy.yml` — он собирает игру
и публикует её на Pages после каждого push в `main`.

1. Создай репозиторий на https://github.com/new и запушь проект:

```bash
git init
git add .
git commit -m "Перерождение Героя: Клинок Богини"
git branch -M main
git remote add origin https://github.com/<твой-ник>/<репозиторий>.git
git push -u origin main
```

2. Включи публикацию: **Settings → Pages → Source: GitHub Actions**.

3. Открой вкладку **Actions** — workflow «Deploy to GitHub Pages» прогонится сам
   (или запусти его кнопкой **Run workflow**). Через пару минут игра будет доступна на
   `https://<твой-ник>.github.io/<репозиторий>/`.

> Пути к ассетам относительные (`--base=./`), поэтому править `vite.config.ts` не нужно —
> работает и на pages-поддомене, и на кастомном домене.
