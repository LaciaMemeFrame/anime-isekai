# Перерождение Героя: Клинок Богини ⚔️

Аниме 2D слэшер с элементами RPG и гачи на React + Canvas.

## Сюжет

Кай погибает под колёсами грузовика в нашем мире. Богиня Астрея дарует ему вторую жизнь в
Элирии — мире, который пожирает Владыка Демонов Зеррис. Пройди три главы (Лес Забвения →
Пепельный Город → Цитадель Владыки), победи боссов, прокачай героя и собери отряд из трёх
героинь — Арии, Юки и Лиры. В финале они станут твоими жёнами. 💍

## Геймплей

- **WASD** — движение, **ЛКМ / J** — комбо-атаки, **SPACE** — рывок с неуязвимостью
- **Q** — Лунная волна, **E** — Ярость Героя (копится от ударов), **ESC** — пауза, **M** — звук
- Волны демонов + боссы в конце каждой главы (у Владыки — 3 фазы и ярость)
- RPG: опыт, уровни, выбор усилений (вампиризм, крит, скорость и др.)
- Гача-призыв за кристаллы: редкие / эпические / легендарные благословения
- Возрождение после смерти за 40 кристаллов, лучший забег в localStorage

## Запуск локально

```bash
npm install
npm run dev
```

## Хостинг на GitHub Pages

1. Создай репозиторий на https://github.com/new и запушь проект:

```bash
git init
git add .
git commit -m "Перерождение Героя: Клинок Богини"
git branch -M main
git remote add origin https://github.com/<твой-ник>/<репозиторий>.git
git push -u origin main
```

2. Собери проект и опубликуй `dist/`:

```bash
npm run build
npx gh-pages -d dist
```

3. В настройках репозитория: **Settings → Pages → Source: gh-pages**.
   Игра откроется по адресу `https://<твой-ник>.github.io/<репозиторий>/`.

> Совет: если ассеты не грузятся, добавь в `vite.config.ts` поле `base: "/<репозиторий>/"`.
